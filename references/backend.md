# Backend notes

The persistent Python service validates window and workspace selection, computes rectangles within the display's usable frame, and sends a JSONL request to one owned native helper. The client connects over a per-user Unix socket (0600), starting the service on demand. The native helper initializes AppKit and SkyLight once; ordinary one-shot requests remain available for diagnostics. The helper is compiled locally as `scripts/windowbridge` on the first run or after its source changes.

The helper reads window metadata from Core Graphics and Spaces metadata from SkyLight. It uses the SkyLight bridge for cross-Space moves, based on [yabai's Space manager](https://github.com/asmvik/yabai/blob/dd845723416f5fe92af49fad5ebab00369e07edd/src/space_manager.c). Accessibility changes window positions and sizes. Inactive-Space windows may be absent from the usual Accessibility list, so the helper uses [yabai's window lookup approach](https://github.com/asmvik/yabai/blob/dd845723416f5fe92af49fad5ebab00369e07edd/src/window_manager.c) to match a window in the authorized process. The local cache at `~/.cache/codex-workspace-layout/ax-tokens.json` records process IDs, window IDs, and element identifiers. No window images or document contents are cached.

The helper checks window ownership and verifies destination Space and geometry after changes. An app can impose a minimum window size. Try larger cells if it cannot reach the requested rectangle. Geometry checks allow two points of rounding. A batch can partially succeed, so read back the current state before retrying a failed batch.

New windows and expected dialogs require process/workspace assignment before the triggering operation. The bridge class `SLSBridgedProcessAssignToSpaceOperation` accepts `initWithProcess:spaceID:`. `prepare` only submits assignment for an inactive dedicated process and refuses existing windows elsewhere. Its response is not a readiness certificate. Controlled adapters must verify their first windows and dialogs. The old generic `open` path is disabled: non-activating configuration and hiding did not prevent an observed wrong-Space window. Placing it afterward is not an acceptable fallback.

Metadata snapshots query each window's Space membership once and cache bundle IDs per PID within the snapshot. The service keeps a bounded-age metadata cache; fresh selection is required for vacancy, automatic allocation and positional primary-window selectors. Explicit identities can reuse recent metadata because the native layer validates the live PID, app and source Space, then reads back the actual destination and geometry. Updating changed windows does not mark the entire cached snapshot fresh.

The stream never retries an uncertain mutation. A batch can have partially completed before a timeout or error. Inspect current scoped metadata and plan the next action from the result. Native document identity, load completion, media behavior and exported artifacts are separate application-adapter responsibilities. The PowerPoint experiment demonstrated native PDF export and OpenXML save/reopen, but it is not a universal document-opening adapter.

The tool does not adjust macOS privacy settings, SIP, or Space preferences. `accessibility` reports whether the helper has Accessibility access, and `bridgedMoveAvailable` reports whether the required bridge exists. Apple silicon macOS 27.0 was exercised with PowerPoint and Finder windows. Controlled PowerPoint native operations were exercised on task copies; generic opening remains disabled. After a macOS update, check capability output and actual results on an authorized window before relying on the workflow.
